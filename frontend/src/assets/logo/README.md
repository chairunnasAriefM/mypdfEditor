# Logo kustom

Taruh file logo Anda di folder ini. Jika belum ada, aplikasi memakai tampilan bawaan.

| File | Dipakai untuk | Saran |
|---|---|---|
| `bubble.png` / `.svg` / `.webp` / `.jpg` | Isi bulatan melayang | Persegi, minimal 256×256, PNG transparan atau gambar penuh. Dipotong menjadi lingkaran. |
| `app.png` / `.svg` / `.webp` / `.jpg` | Logo merek di header dan sidebar fullscreen | Persegi, minimal 128×128. |

Ikon file `.exe` dan ikon taskbar diatur terpisah di `build/appicon.png` (lihat `build/README.md`).

Setelah mengganti file, jalankan ulang `wails dev` atau `wails build`.
